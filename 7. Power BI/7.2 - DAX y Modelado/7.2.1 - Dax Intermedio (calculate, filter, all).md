## Contexto de la sesión

En S04 aprendimos a escribir medidas DAX básicas: `SUM`, `COUNTROWS`, `DIVIDE` y el patrón `VAR / RETURN`. Esas medidas siempre respetan el contexto de filtro tal como está en el momento de la evaluación.

Hoy damos el salto más importante del DAX intermedio: aprender a **modificar ese contexto desde dentro de la medida**. Con `CALCULATE` podemos añadir filtros, eliminarlos o sustituirlos. Con `FILTER` construimos tablas filtradas dinámicamente. Con `ALL` y sus variantes borramos filtros para calcular sobre el total.

Estas tres funciones son la base de prácticamente todas las medidas avanzadas: porcentajes sobre totales, comparaciones entre categorías, rankings y análisis temporales. Todo lo que venga en las sesiones siguientes usa estas piezas.

## 1. CALCULATE: Modificando el Contexto de Cálculo

### ¿Qué es CALCULATE?

CALCULATE es la función más versátil y poderosa en DAX. Permite evaluar una expresión en un contexto de filtro modificado. En otras palabras, cambia las reglas del juego para cómo se calculan las medidas, aplicando filtros adicionales o removiendo existentes.

### Sintaxis Básica

```
CALCULATE(<expresión>, <filtro1>, <filtro2>, ...)
```

- **expresión**: La medida o expresión a evaluar.
- **filtro1, filtro2, ...**: Condiciones de filtro a aplicar.

### Ejemplos Prácticos

#### Ejemplo 1: Ventas Totales por Año
Supongamos que tenemos una tabla `Ventas` con columnas `Fecha` y `Monto`.

Medida básica:
```
Ventas Totales = SUM(Ventas[Monto])
```

Con CALCULATE para filtrar por año:
```
Ventas 2023 = CALCULATE(SUM(Ventas[Monto]), YEAR(Ventas[Fecha]) = 2023)
```

#### Ejemplo 2: Usando CALCULATE con el Dataset Reservas
Asumiendo que `reservas.csv` tiene columnas como `Fecha_Reserva`, `Precio_Total`, `Estado`, etc.

Medida para reservas confirmadas:
```
Reservas Confirmadas = CALCULATE(SUM(Reservas[Precio_Total]), Reservas[Estado] = "Confirmada")
```

#### Ejemplo 3: Múltiples Filtros
```
Ventas Q1 2023 = CALCULATE(SUM(Ventas[Monto]), YEAR(Ventas[Fecha]) = 2023, MONTH(Ventas[Fecha]) IN {1, 2, 3})
```

### Conceptos Clave con CALCULATE
- **Contexto de Fila**: CALCULATE ignora el contexto de fila y aplica el contexto de filtro.
- **Evaluación**: La expresión se evalúa después de aplicar todos los filtros.

## 2. FILTER: Creando Tablas Filtradas

### ¿Qué es FILTER?

FILTER es una función de tabla que devuelve una tabla filtrada según una condición específica. Es útil para crear subconjuntos de datos dinámicos.

### Sintaxis

```
FILTER(<tabla>, <condición>)
```

- **tabla**: La tabla a filtrar.
- **condición**: Una expresión booleana que determina qué filas incluir.

### Ejemplos Prácticos

#### Ejemplo 1: Productos con Alto Precio
```
Productos Caros = FILTER(Productos, Productos[Precio] > 100)
```

#### Ejemplo 2: Reservas Recientes
Usando el dataset reservas:
```
Reservas Recientes = FILTER(Reservas, DATEDIFF(Reservas[Fecha_Reserva], TODAY(), DAY) <= 30)
```

#### Ejemplo 3: Combinado con Otras Funciones
```
Ventas Productos Caros = SUMX(FILTER(Productos, Productos[Precio] > 100), Productos[Precio] * Productos[Cantidad])
```

### Notas Importantes
- FILTER siempre devuelve una tabla, no un valor escalar.
- Se usa comúnmente dentro de funciones como SUMX, AVERAGEX, etc.

## 3. ALL: Removiendo Filtros

### ¿Qué es ALL?

ALL es una función que remueve todos los filtros aplicados a una tabla o columna específica. Es esencial para cálculos que necesitan ignorar ciertos filtros del contexto actual.

### Sintaxis

```
ALL(<tabla o columna>)
```

### Ejemplos Prácticos

#### Ejemplo 1: Porcentaje del Total
```
Porcentaje Ventas = DIVIDE(SUM(Ventas[Monto]), CALCULATE(SUM(Ventas[Monto]), ALL(Ventas)))
```

#### Ejemplo 2: Usando ALL con Columnas Específicas
```
Ventas Totales por Categoría = CALCULATE(SUM(Ventas[Monto]), ALL(Ventas[Categoría]))
```

Esto calcula las ventas totales ignorando filtros en la columna Categoría.

#### Ejemplo 3: Con el Dataset Reservas
```
Porcentaje Reservas Confirmadas = DIVIDE(
    CALCULATE(COUNTROWS(Reservas), Reservas[Estado] = "Confirmada"),
    CALCULATE(COUNTROWS(Reservas), ALL(Reservas))
)
```

### Variantes de ALL
- **ALL()**: Remueve todos los filtros.
- **ALL(<columna>)**: Remueve filtros solo de esa columna.
- **ALL(<tabla>)**: Remueve filtros de todas las columnas de la tabla.
- **ALLSELECTED**: Similar a ALL pero respeta los filtros del usuario.

## 4. Combinando CALCULATE, FILTER y ALL

### Ejemplo 1: Ventas de Productos Seleccionados
```
Ventas Productos Seleccionados = CALCULATE(
    SUM(Ventas[Monto]),
    FILTER(ALL(Productos), Productos[Categoría] = "Electrónicos")
)
```

### Ejemplo 2: Crecimiento Anual Ignorando Filtros
```
Crecimiento Anual = DIVIDE(
    SUM(Ventas[Monto]) - CALCULATE(SUM(Ventas[Monto]), DATEADD('Calendario'[Fecha], -1, YEAR)),
    CALCULATE(SUM(Ventas[Monto]), DATEADD('Calendario'[Fecha], -1, YEAR))
)
```

### Ejemplo 3: Top N con FILTER
```
Top 5 Productos = TOPN(5, ALL(Productos), [Ventas Totales])
```

## 6. Lo que DAX ha hecho por debajo

Cada vez que Power BI evaluó una medida con `CALCULATE`, ocurrió esto en el motor:

**CALCULATE crea un nuevo contexto de filtro**

```
[Revenue Confirmado] = CALCULATE([Revenue Total], reservas[status] = "Confirmed")
```

Power BI toma el contexto de filtro existente (por ejemplo, "hotel = Málaga" desde el eje del visual), añade el filtro `status = "Confirmed"` y evalúa `[Revenue Total]` en ese contexto combinado. El filtro nuevo no reemplaza los anteriores: los acumula, salvo que haya un conflicto explícito sobre la misma columna.

**ALL elimina el filtro de columna antes de evaluar**

```
[% Revenue] = DIVIDE([Revenue Total], CALCULATE([Revenue Total], ALL(reservas)))
```

`ALL(reservas)` devuelve una tabla con todas las filas sin ningún filtro. `CALCULATE` usa esa tabla como nuevo contexto, ignorando completamente los filtros del visual. El denominador es siempre el total global. El numerador usa el contexto del visual (hotel, canal, mes). El equivalente SQL sería:

```sql
SELECT
    hotel,
    SUM(revenue) AS revenue_hotel,
    SUM(revenue) * 1.0 / (SELECT SUM(revenue) FROM reservas) AS pct
FROM reservas
GROUP BY hotel;
```

**FILTER itera fila a fila antes de que CALCULATE actúe**

```
CALCULATE([Revenue Total], FILTER(reservas, reservas[revenue] > 500))
```

Primero `FILTER` recorre cada fila de `reservas` evaluando la condición; devuelve una tabla reducida. Luego `CALCULATE` aplica esa tabla como contexto. `FILTER` ocurre dentro del contexto de filtro actual, no sobre la tabla completa sin filtros. Si el visual ya tiene filtrado "año = 2024", `FILTER` solo ve las filas de 2024.

**CALCULATE anidado: los filtros se acumulan en capas**

```
CALCULATE(
    CALCULATE([Revenue Total], reservas[status] = "Confirmed"),
    reservas[channel] = "Direct"
)
```

El `CALCULATE` exterior añade el filtro de canal. El interior añade el filtro de estado. El motor aplica ambos: reservas confirmadas Y del canal directo. Si ambos filtros afectan a la misma columna, el más interno gana.

## 7. Errores comunes

| Error | Causa | Solución |
|---|---|---|
| `CALCULATE` ignora el filtro que pasas | Pasaste una expresión booleana que DAX no puede convertir en filtro de tabla | Usa `FILTER(tabla, condición)` en lugar de la expresión directa cuando la condición no es simple `columna = valor` |
| `ALL` no elimina el filtro esperado | Usaste `ALL(columna)` pero hay un filtro en otra columna relacionada | `ALL(tabla)` elimina todos los filtros de la tabla; `ALL(columna)` solo elimina el filtro de esa columna específica |
| Circular dependency al crear la medida | La medida se referencia a sí misma, directa o indirectamente | Revisar si la medida base que llama `CALCULATE` depende de otra medida que vuelve a llamar a la primera |
| `FILTER` devuelve tabla vacía y la medida da BLANK | La condición de `FILTER` nunca se cumple en el contexto actual | Revisar los valores reales de la columna filtrada; considerar `IF(COUNTROWS(FILTER(...)) = 0, 0, ...)` |
| `ALLSELECTED` devuelve el mismo valor que `ALL` | No hay un slicer o filtro de usuario activo | Es comportamiento correcto; `ALLSELECTED` solo difiere de `ALL` cuando el usuario ha seleccionado algo en un slicer |
